Key Capabilities

Built for Real-World Coaching Needs

Clean architecture, automated workflows, and reliable performance out of the box.

Duplicate-Safe Attendance

Re-marking existing batch attendance modifies the same day's record cleanly without duplicate SQL key collisions, keeping parent contact logs synchronized.

Razorpay Payment Gateway

Integrated order generation, checkout modal, CSRF validation, and webhook listener for instant automated receipt confirmation.

Dynamic Marksheet Generator

Calculates percentages, letter grades, and passing statuses automatically from real exam marks, complete with clean print stylesheets.

Strict Role-Based Security

Protected by session guards (`auth_check.php`), CSRF token verification on all POST endpoints, and password hashing using Bcrypt.

Auto-Provisioned Schema

`config/db.php` detects and creates missing database tables (exams, results, payments, users) dynamically so setup is painless.

Multi-Institute Isolation

Every admin, teacher, and student belongs to a specific institute tenant with auto-scoped data filtering preventing cross-institute leaks.
